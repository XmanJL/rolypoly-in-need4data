## Developer Setup and Guidelines

To run code for this project:
1. Download the car accident dataset from the competition and save it under: `rolypoly-in-need4data/data/US_Accidents_March23_sampled_500k.csv`
2. Set up the virtual environment with the required dependencies in the terminal:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
3. All the source code for this datathon can be accessed in the `/experiment` folder.
